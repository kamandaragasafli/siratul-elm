📖 Yeni kitab əlavə etmək

  1. Kitab adı yazın mütləq
  2. İstəsəniz müəllif, qısa təsvir və mövzuları doldurun.
  3. Qapaq şəkli seçin — Sirac tətbiqində kitabxanada belə görünəcək.
  4. Tətbiqdə göstər qalsın — kitab dərhal tətbiqdə görünsün.
  5. Aşağıdakı «Fəsillər» bölməsində fəsil adı və oxunacaq mətni yazın. Sıra və ID avtomatik yaranır.
  6. Sonra aşağıdakı Saxla və davam et düyməsinə basın.

«Kitab ID» və digər texniki sahələr aşağıda qatlanmış blokdadır — adətən toxunmaq lazım deyil. Boş fəsil sətirini boş buraxa bilərsiniz.
